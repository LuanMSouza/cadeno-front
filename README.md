## 📋 Sobre

Aplicação web do Cadeno com interface responsiva, consumindo a API REST.

## 🚀 Como Rodar

**Pré-requisitos:** Node.js 18+ e [API do Cadeno](https://github.com/LuanMSouza/cadeno-back) rodando.

```bash
git clone https://github.com/LuanMSouza/cadeno-front
cd cadeno-front
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).
